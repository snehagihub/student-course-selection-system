 # Student Course Selection and Management System

A menu-driven C++ mini-project demonstrating Data Structures and Algorithms (DSA) for managing courses and student registrations.

## Objectives

- Manage course records.
- Search for courses by ID.
- Register students and manage course selections.
- Check prerequisites and available seats.
- Demonstrate practical applications of DSA.

## Technologies

- C++
- Data Structures and Algorithms
- Object-Oriented Programming
- File Handling

## DSA Concepts

- Singly Linked List — dynamic course management
- Searching and Sorting — course lookup and organization
- Queue — course waiting list
- Stack — undo recent operations
- Graph — course prerequisite relationships

## Current Features

- Display available courses
- Add courses
- Search for courses by ID
- Prevent duplicate course IDs
- Store course records using a linked list

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Compile `main.cpp` using a C++ compiler.
4. Run the generated executable.

Example compilation command:

```bash
g++ main.cpp -o course_system
```

Run on Windows:

```bash
course_system.exe
```
