# Student Course Selection and Management System

A console-based application developed using C++ to manage students, courses, and course enrollments.

## 📌 About the Project

The Student Course Selection and Management System is a C++ project designed to simplify basic student and course management.

It allows users to register students, manage course information, enroll students in courses, track available seats, and save data using file handling.

This project demonstrates the practical implementation of **Object-Oriented Programming concepts, structures, linked lists, dynamic memory allocation, and file handling in C++**.

## ✨ Features

### 📚 Course Management
- Add new courses.
- Display all available courses.
- Search for courses by ID or name.
- Update course information.
- Delete courses when permitted.
- Sort courses by name or credits.

### 👩‍🎓 Student Management
- Register new students.
- Display registered students.
- Search students by ID.
- Prevent duplicate student IDs.

### 📝 Course Enrollment
- Enroll students in courses.
- Check whether students and courses exist.
- Prevent duplicate enrollments.
- Check course seat availability.
- View courses selected by a student.
- Drop selected courses.
- Restore available seats when a course is dropped.

### 💾 Data Management
- Save course information.
- Save student information.
- Save enrollment information.
- Load saved information when the program starts.
- Release dynamically allocated memory when appropriate.
